# Privacy Policy

**Impostor Guard** (the "Bot") is a Telegram bot that detects and removes users
impersonating a group's admins, protected members, or the group itself.

## What the Bot stores

The Bot only works inside groups an admin has deliberately added it to. In those
groups it stores:

| Data | Why | Where it comes from |
|---|---|---|
| Telegram user ID | The stable, pseudonymous key for every record | Telegram |
| Username (`@handle`) | Compared against protected handles | Telegram |
| Display name (first / last) | Compared against protected names | Telegram |
| Profile photo **hash** | Compared against protected photos | Computed by the Bot |
| Bio text | Only for a user who was flagged, as a snapshot of the evidence | Telegram (MTProto) |
| Group ID, title and logo hash | To protect the group's own identity | Telegram |
| Detection records | What was matched, the confidence score, and what action was taken | Generated by the Bot |
| Admin actions | Who banned, whitelisted or changed settings, and when | Generated by the Bot |

### What the Bot does **not** store

- **Message content.** Because it is a group administrator, Telegram delivers
  group messages to the Bot. It uses only the *fact* that you posted, as a
  trigger to check your profile — it never inspects, stores or forwards the text
  of what anyone writes.
- **Profile photos themselves.** Only a perceptual hash — a short fingerprint
  used for comparison. The image is not retained.
- **Phone numbers, contacts, location, or payment information.**
- **Anything from private chats**, other than the group selection an admin makes
  while configuring the Bot.

## Why it stores it

To detect impersonation. Comparing a new or changed profile against the
identities a group has chosen to protect is the Bot's entire function, and it
cannot be done without holding those identities and a record of what was
compared.

Detection records exist so an admin can review and reverse a decision. That
matters: an automated ban that cannot be audited or undone is worse than no ban.

For users in the EU/UK, the lawful basis is **legitimate interests** — protecting
group members from impersonation and fraud. You can object at any time using the
contact above.

## How long it is kept

Old records are deleted automatically on a daily schedule:

| Data | Retained for |
|---|---|
| Detection records (`logs`) | 90 days |
| Sweep results | 90 days |
| "Already checked" markers | 180 days |
| Admin action audit trail | 365 days |
| Name-change tracking | 1 day |
| False-positive grace records | Until the 30-day grace window expires |
| Protected identities, group settings, keywords | While the Bot is in the group |

Removing the Bot from a group stops all collection for that group immediately.
To have the group's stored data deleted as well, contact the operator.

## Who it is shared with

**Nobody.** The data is not sold, rented, or shared with advertisers or analytics
providers.

Two disclosures worth making plainly:

**Infrastructure.** The Bot runs on Railway and stores data in a PostgreSQL
database hosted there. Railway processes this data on the operator's behalf.
Operational logs (which contain numeric user IDs, never names) are retained by
Railway's logging platform.

**Cross-group blocklist.** A user manually banned in one group *may* be flagged
in other groups the same operator runs. Only the user ID, username, display name
and a short reason are shared this way, and only from groups the operator has
explicitly designated as trusted. Bans from any other group are advisory: they
raise an alert for a human to review and never remove anyone automatically. A
group can opt out entirely with `/blocklist off`.

## Your rights

You may ask the operator to:

- tell you what the Bot holds about you,
- correct it,
- delete it,
- or object to the processing.

Use the contact above. If you were banned and believe it was a mistake, say so —
the Bot records a confidence score and the reason for every action, so an admin
can check the evidence and reverse it. Reversal is a single button for them.

---

## Automated decisions

The Bot can ban or remove a user automatically when its confidence is high. This
is an automated decision, and it is deliberately reversible:

- every action is logged with the reason and a confidence score,
- every alert carries one-tap **Unban** and **Whitelist** buttons,
- a reversal records a 30-day grace window so the same user is not re-flagged,
- and a group can be configured to **alert only**, taking no automatic action at
  all.

If you believe an automated decision about you was wrong, contact the group's
admins or the operator.
